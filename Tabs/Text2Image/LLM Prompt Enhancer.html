LLM Prompt Enhancer

The ✨ button next to the prompt box rewrites your prompt with the model chosen here. For automatic enhancement while generating, switch on the LLM Prompt Enhancer parameter group. Wildcards (<wildcard:name>, <random:a|b>, __name__, {a|b}), LoRAs and other prompt syntax are kept as they are.

You can use the enhancer, but only an admin can change these settings.
